# Free Wedding Website Templates

Three free, responsive, single-file wedding websites. No build step, no JavaScript. MIT licensed.

| Template | Look |
|---|---|
| `sage-garden/` | ivory and sage, script names |
| `midnight-gold/` | dark navy and gold, classic serif |
| `blush-modern/` | white and blush, clean modern |

Each includes: hero with names and date, Our Story, Schedule, Travel & Stay, Registry, FAQ, and an RSVP form.

## Use it
1. Download or fork this repo, open a template's `index.html`, and replace the sample names, dates, places and text.
2. RSVP: static sites can't store form replies. Set the form's `action` to a form service such as Formspree, or link to a Google Form instead.
3. Publish free with GitHub Pages (Settings → Pages → deploy from branch) or Netlify Drop.

Fonts load from Google Fonts (SIL Open Font License).
